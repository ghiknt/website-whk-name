I am planning an upgrade to my network configuration.  This is a brief survey
the current state of available software to use for my configuration.  My
current preference is OpenWRT but it has been a couple of years since I looked
at alternatives.

Features I am looking for...
- Free and Open Source (FOSS)
- Security
- Stable for Core equipment, Flexible for Dev equipment  
- Command line configuration/management
- Support for scripted remote configuration
- CPU Support
  - ARM - WRT1200AC
  - MIPS - WNDR3700v2
  - AMD64/X86_64 - VP6650

* Network OS options
** Final Candidates
*** OpenWRT
- Supported Hardware: WNDR3800, WRT1200AC
- No longer supported: ECB350 (ended 2022)
*** Mainline Linux
- References
  - [[https://wiki.debian.org/InstallingDebianOn/Linksys/WRT1200AC][InstallingDebianOn Linksys WRT1200AC]]
**** IPFire
- Supports ARM64/x86_64
- Consider using VM version inside protectli
**** danosproject.org
- Supported: KVM, x86
- Last updated in 2021 is it still active?
- Consider Using VM version inside protectli
**** VyOS
- *Freemium Model*
  - Need to compare features in LTS vs Stream.  May just be better support which I don't mind.
- Consider Using in VM inside protectli
- Con: doesn't support gpg verification for release signing.  Would need to research minisign to determine if I trust.
- Pro: Commandline Interface appears to be like other Network OS's I used previously
** Other considered options
*** bsd alternatives
Both pfSense and OPNsense look interesting and if they supported the WRT1200AC
I would probably use them. They are not interesting enough to beat out a mainstream
linux distro for the VP6650 though.
**** pfSense
- Points to FreeBSD14 compatibilty information.
**** OPNsense
- Supported Hardware: VP6650 (Only support AMD64/X86_64)
*** ProxMox
- *Freemium Model*
  - Quick perusal doesn't make it easy to see what is the value added capabilities in the  "enterprise repo"

Seriously considered for VP6650 as the main install but it does not support full disk encryption in installer so
I would need to install on top of debian.  If I have to do that I will just install my own
os from scratch since WebUI is not a big deal for me.
*** DD-WRT
- Supported Hardware: WNDR3800, WRT1200AC
I don't see anything to make me switch from OpenWRT.  Looks similar but
website is not as easy to use.
*** Tomato/freshtomato
- Doesn't Support any of my hardware
*** nvidia cumulus linux
- While bases on Cumulus Networks version I do not see a way to get/look at
  source from [[https://www.nvidia.com/en-us/networking/ethernet-switching/cumulus-linux/][Nvidia's page]].  Assuming they have closed sourced it for now.
