* Configurations
** Common

- Install openwrt image and boot
  - For WRT1200ACv1 the default linksys password is ~admin~
- Manual configuration
  - After switching to openwrt firmware the initial root password is blank
  - Set root password
  - Set temporary address for integration: ~Network | Interfaces | lan | Edit~
    - ipv4 address: 10.77.128.254
    - ipv4 netmask: 255.255.255.0
    - save
  - Save & Apply
