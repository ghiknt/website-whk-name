*** First Partition - unencrypted ext4
Needed inorder to properly shows up as "Data Block Device" while still attached to sys-usb qube.
TODO: Determine why some USB storage devices seem to require this but others don't

```
mkfs.ext4 -L ioSafeSoloReadme /dev/sda1
```

*** Second (Main) Partition - LUKS + BTRFS

**** Initial

```
cryptsetup luksFormat --label ioSafeSoloData /dev/sda2
cryptsetup open /dev/sda2 ioSafeSoloData
dd if=/dev/zero of=/dev/mapper/ioSafeSoloData bs=1024M status=progress
mkfs.btrfs --data dup --metadata dup --label ioSafeSoloData /dev/mapper/ioSafeSoloData
```
