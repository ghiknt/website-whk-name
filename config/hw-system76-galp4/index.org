** PCI Express Gigabit Ethernet Controller does not support PCI device reset

Ref: https://www.qubes-os.org/doc/pci-troubleshooting/#unable-to-reset-pci-device-errors

During post install configuration "sys-net" fails to start due to the PCI Express Gigabit
Ethernet Controller failing PCI device reset

- Current mitigation - Set ```no-strict-reset=True``` for sys-net using
  Qubes Manager | sys-net | Settings | Devices | Configure strict reset for PCI devices

** Configure Memory for multi monitor
- In dom0 terminal as "user" set enough memory for 1200x1920 (Portrait) + 1920x1200 (Landscape) + 1920x1080 (Laptop Landscape)
 
    ```
    HEIGHT=1920
    WIDTH=$((1200 + 1920 + 1920))
    qvm-features dom0 gui-videoram-min $(($WIDTH * $HEIGHT * 4 / 1024))
    qvm-features dom0 gui-videoram-overhead 0
    ```

** Update grub to tell qubes-os to hide device

```
# Generic Linux Option
# Disable NVME PCI
pci-stub.ids=0000:06:00.0

# Disable Both NVME and SATA PCI
pci-stub.ids=0000:06:00.0,0000:00:17.0

# Disable ata access to WD 1TB Drive individually
libata.force=5:disable

# Qubes Specific Option
rd.qubes.hide_pci=ID
grub2-mkconfig -o /boot/grub2/grub.cfg
reboot
```
