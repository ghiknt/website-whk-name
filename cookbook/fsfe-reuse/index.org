* Setup

- Ensure [[https://podman.io/][PODMAN]] is installed.
  - Debian 12: =apt-get install podman=
- Pull fsfe-container
  - By Default stores containers in =~/.local/share/containers/storage/=
    
  #+begin_src bash
    podman pull docker.io/fsfe/reuse
  #+end_src

* Running

- References: [[https://reuse.readthedocs.io/en/stable/readme.html#run-in-docker][reuse | Run in Docker]]
- lint

  =podman run --rm --volume $(pwd):/data fsfe/reuse lint=

- Generate spdx file

  =podman run --rm --volume $(pwd):/data fsfe/reuse  spdx -o out.spdx=

- Pull License List

  #+begin_src bash
    podman run --rm --volume $(pwd):/data fsfe/reuse download \
	   CC-BY-SA-4.0 \
	   AGPL-3.0-or-later \
	   GPL-3.0-or-later  \
	   Apache-2.0
  #+end_src

  =podman run --rm --volume $(pwd):/data fsfe/reuse download=

* SPDX Examples
** My default licence for Literate Org Mode Files

# REUSE-IgnoreStart
#+begin_src org
  - SPDX-License-Identifier: CC-BY-SA-4.0 or AGPL-3.0-or-later
  - SPDX-FileCopyrightText: 2025 WHK <develop@whk.name>

** Including SPDX examples that should be ignored by Reuse

#+begin_src org
  # REUSE-IgnoreStart
  Content containing example SPDX
  # REUSE-IgnoreEnd
#+end_src

** Specify a SPDX-Snippet for and INCLUDE example

This will ensure the resultant HTML has SPDX tags specifying
the License of the example

# REUSE-IgnoreStart
#+begin_example
  ,#+BEGIN_EXPORT html
  <!--    
    SPDX-SnippetBegin
    SPDX-License-Identifier: GPL-3.0-or-later
    SPDX-SnippetCopyrightText: Sebastian Rose, Hannover, Germany - sebastian_rose at gmx dot de
  -->
  ,#+END_EXPORT
  ,#+BEGIN_details
  ,#+HTML: <summary>org-info-src.js code listing</summary>
  ,#+INCLUDE: "org-info-src.js" example
  ,#+END_details
  ,#+BEGIN_EXPORT html
  <!--    
    SPDX-SnippetEnd
  -->
  ,#+END_EXPORT
#+end_example
# RESUSE-IgnoreEnd
