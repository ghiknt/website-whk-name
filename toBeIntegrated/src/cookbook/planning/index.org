

* Methodology

** Goal
   A work pattern that captures tasks/ideas as they develop and then
   allows working on tasks when mood/time permits.

** Options
  
  - Consider [[https://orgmode.org/worg/org-gtd-etc.html][GTD]] since it
    appears to be the most documented integration and initial review appears
    to provide main features.
    - PRO: [[https://orgmode.org/list/26163.1199054673@localhost/][No Priorities to reevaluate]]
    - CON:
      - Daily/Weekly Reviews to conduct
      - Most examples use single project file containing a bunch of
	projects instead of containing project plans with code, etc.
	- But [[https://orgmode.org/list/76f7cd71190bcff68e57e71d163fe49f@science.uva.nl/][this post]] seems to fit the way I want to work
